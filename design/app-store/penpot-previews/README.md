The masters use the unmodified official Apple Product Bezels: MacBook Pro M5
16-inch in Space Black and iPad Air 13-inch (M4) in Space Gray. Only uniform
scaling and screenshot placement behind the transparent screen openings are
used.

## Mac order

1. `MAC 01 — Shorts removed — EN`
   - Left: YouTube home before enabling the filters.
   - Right: the same home page with Shorts/feed removed.
2. `MAC 02 — Clean home — EN`
   - A full clean-home result with the extension active.
3. `MAC 03 — Cleaner video pages — EN`
   - Left: video page with recommendations/comments.
   - Right: the same video page with distractions hidden.
4. `MAC 04 — Controls — EN`
   - Extension popover with all three controls visible.
5. `MAC 05 — Safari native — EN`
   - Extension popover on the left; final clean result on the right.

## iPad order

1. `IPAD 01 — Remove Shorts — EN`
   - Current old annotated source. Replace with a fresh full iPad capture when available.
2. `IPAD 02 — Clean home — EN`
   - Drop a full iPad home-feed capture with the Shorts shelf hidden.
3. `IPAD 03 — Focused video — EN`
   - Drop a full iPad video page with recommendations hidden.
4. `IPAD 04 — Controls — EN`
   - Drop the iPad extension settings/popover with all toggles visible.
5. `IPAD 05 — Safari native — EN`
   - Drop a normal Safari browsing/search/subscriptions result that proves the rest of YouTube still works.

## Replacement rule

Replace only the layer whose name begins with `DROP —` (or `iPad Device Screen` on slide 1). Keep the screenshot at its native 3:4 ratio and use fit/contain, never crop. The Mac screen layers are already fitted at their original 3456×2234 ratio.
